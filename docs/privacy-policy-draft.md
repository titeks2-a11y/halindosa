# 할인도사 개인정보처리방침 초안

할인도사는 국내 할인 특가 정보를 제공하는 앱입니다. 비회원도 모든 특가 정보를 볼 수 있으며, 사용자가 이메일 또는 소셜 로그인을 선택하는 경우 계정 기능 제공을 위해 필요한 최소 정보를 처리합니다.

## 수집 또는 저장되는 정보

- 비회원 기기 데이터: 찜한 특가, 최근 본 상품, 동의 설정
- 회원 계정 정보: 이메일, 닉네임, Supabase Auth 사용자 ID
- 소셜 로그인 정보: Google/Kakao 등 인증 제공자가 전달한 이메일, 고유 식별자, 프로필 이름 일부
- 회원 기능 데이터: 찜한 특가, 최근 본 상품, 관심 카테고리, 알림/마케팅 수신 설정
- 서비스 품질 데이터: 특가 클릭, 링크 이동, 가격 오류 신고 등 운영 검수에 필요한 이벤트

전화번호, 주소, 결제 정보, 위치 정보는 수집하지 않습니다.

## 이용 목적

- 로그인 유지와 계정 식별
- 찜한 특가와 최근 본 상품 동기화
- 관심 카테고리와 알림 설정 제공
- 잘못된 가격/품절/링크 오류 신고 처리
- 외부 판매처 이동과 제휴 성과 확인
- 서비스 안정성 및 품질 개선

## 외부 링크

사용자가 구매 버튼을 누르면 판매처 또는 제휴사 웹사이트로 이동할 수 있습니다. 외부 사이트의 개인정보 처리, 결제, 배송, 환불은 해당 사이트의 정책을 따릅니다.

## 보관 기간

- 비회원 기기 데이터: 사용자가 앱 내 기기 데이터 관리, 브라우저 저장소 삭제, 앱 데이터 삭제를 실행할 때까지 보관
- 회원 계정 정보: 회원 탈퇴 또는 삭제 요청 시 삭제
- 찜, 최근 본 상품, 관심 카테고리, 가격 알림 데이터: 회원 탈퇴 또는 사용자의 삭제 요청 시 삭제
- 통계용 클릭 로그: 회원 탈퇴 시 사용자 식별자를 제거해 개인을 식별할 수 없는 형태로 보관 가능
- 가격/품절/링크 오류 신고: 운영 품질 관리와 분쟁 방지를 위해 필요한 기간 동안 보관 가능하며, 개인 식별 정보는 최소화

## 처리 위탁 및 제3자 제공

- Supabase: 이메일/소셜 로그인, 세션 유지, 계정 기반 찜/최근 본 상품/관심 카테고리 동기화
- Google/Kakao 등 소셜 로그인 제공자: 사용자가 선택한 로그인 인증 처리
- 외부 판매처/제휴사: 사용자가 구매 버튼을 눌러 이동한 뒤 발생하는 결제, 배송, 환불, 개인정보 처리는 해당 판매처 정책에 따름
- 광고/분석/푸시 SDK: 현재 연결하지 않았으며, 도입 시 본 방침과 스토어 데이터 보안 답변을 갱신

## 삭제 방법

비회원 기기 데이터는 앱 내 기기 데이터 관리 또는 앱 데이터 삭제로 제거할 수 있습니다. 회원은 마이페이지의 회원 탈퇴 기능으로 프로필, 찜, 최근 본 상품, 가격 알림 데이터를 삭제할 수 있습니다. 통계용 클릭 로그는 개인을 식별할 수 없도록 익명화합니다.

## 향후 도입 가능 항목

광고 SDK, 분석 SDK, 푸시 알림, 제휴 성과 측정, 고객 문의 기능을 확장하는 경우 수집 항목, 이용 목적, 보관 기간, 제3자 제공 여부를 본 방침에 반영하고 필요한 동의를 받습니다.

## 사용자 권리

사용자는 개인정보 열람, 정정, 삭제, 처리정지 요청을 할 수 있습니다. 회원 탈퇴 또는 데이터 삭제가 필요한 경우 앱 내 마이페이지 또는 고객 문의 창구를 이용할 수 있습니다.

## 문의

개인정보 관련 문의는 앱 내 문의하기 영역 또는 운영자가 고지한 이메일을 통해 접수할 수 있습니다.
