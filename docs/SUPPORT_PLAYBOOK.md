## User Reply Macros

### 가격이 다름

- Internal ID: `price-mismatch`
- Priority: high
- Target response: 영업일 기준 24시간 안에 1차 확인

```text
제보 감사합니다. 할인도사는 직접 판매자가 아니어서 최종 가격은 판매처의 쿠폰, 옵션, 배송지, 재고 상태에 따라 달라질 수 있습니다. 알려주신 상품은 운영 검수 큐에 반영해 가격, 쿠폰 조건, 링크 상태를 확인하겠습니다.
```

### 품절 또는 옵션 선택 불가

- Internal ID: `sold-out`
- Priority: high
- Target response: 영업일 기준 24시간 안에 1차 확인

```text
품절 또는 옵션 불가 제보 감사합니다. 판매처 재고는 빠르게 변동될 수 있어, 운영자가 확인 후 종료 또는 마감 임박/확인 필요 상태로 조정하겠습니다.
```

### 링크 오류 또는 다른 상품으로 이동

- Internal ID: `link-error`
- Priority: critical
- Target response: 가능하면 당일 확인

```text
링크 오류 제보 감사합니다. 할인도사는 실제 상품 상세 URL 또는 공식 혜택 URL만 노출하는 것을 원칙으로 합니다. 해당 링크는 우선 검수 대상으로 올려 도착 페이지, 판매처 도메인, 상품명을 확인하겠습니다.
```

### 혜택 종료 또는 쿠폰 소진

- Internal ID: `benefit-expired`
- Priority: medium
- Target response: 영업일 기준 48시간 안에 확인

```text
혜택 종료 제보 감사합니다. 쿠폰과 무료 혜택은 선착순, 예산, 계정 조건에 따라 조기 종료될 수 있습니다. 운영자가 마감 여부를 확인해 종료 처리 또는 조건 안내를 보강하겠습니다.
```

### 개인정보/계정/삭제 문의

- Internal ID: `privacy-or-account`
- Priority: critical
- Target response: 영업일 기준 24시간 안에 접수 확인

```text
문의 감사합니다. 할인도사는 V1에서 비회원 이용을 기본으로 하며, 로그인은 찜한 특가와 관심 카테고리 이어보기에 사용됩니다. 데이터 확인 또는 삭제 요청은 마이 화면과 개인정보처리방침 안내에 따라 처리하겠습니다.
```

### 스토어 심사/제출 문의

- Internal ID: `store-review`
- Priority: high
- Target response: 제출 당일 확인

```text
스토어 제출 관련 항목은 공개 URL, signed AAB, 실기기 QA, 스크린샷, OAuth 설정처럼 실제 콘솔 증빙이 필요한 작업과 저장소 자동 검증 작업을 구분해 확인하겠습니다.
```

## Escalation Rules

- 결제, 환불, 배송, 교환, 반품은 외부 판매처 고객센터로 안내합니다.
- 링크 오류, 가격 불일치, 품절, 혜택 종료는 운영 검수 큐와 GitHub link report 이슈로 연결합니다.
- 개인정보, 계정 삭제, 인증 문제는 공개 이슈에 민감정보를 남기지 않고 정책 문서와 비공개 지원 채널로 안내합니다.
- Play Console/App Store Connect 제출 문제는 store-submission-blocker 이슈 템플릿을 사용하되, keystore/OAuth secret/콘솔 계정 정보는 기록하지 않습니다.

## Sensitive Data Rule

Never record order numbers, addresses, payment data, passwords, auth codes, Supabase keys, OAuth client secrets, keystore passwords, .env values, or private console screenshots in support tickets or public issues.
