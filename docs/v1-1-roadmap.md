# 할인도사 V1.1 Roadmap

## 목표

V1.0의 특가 탐색 경험을 개인화와 커뮤니티 신뢰 구조로 확장한다.

## 후보 기능

- 회원가입
- 관심 카테고리
- 알림 개인화
- 댓글
- 커뮤니티
- 가격 추적
- 재입고 알림

## 3개월 로드맵

1. 관심 카테고리와 알림 개인화
2. 가격 추적과 가격 이력 히스토리
3. 운영 DB와 관리자 승인 플로우

## 6개월 로드맵

1. 회원 기반 찜/알림 동기화
2. 댓글과 사용자 제보
3. 브랜드 광고와 제휴 리포트
4. 실시간 가격 변동 모니터링

## 보류

결제, 포인트, 현금성 보상은 정책/법무 검토 후 별도 판단한다.
