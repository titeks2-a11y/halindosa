# 할인도사 Play Console 데이터 보안 작성 가이드

## 현재 앱 기준 결론

할인도사는 현재 회원가입 없이 사용할 수 있으며, 이름, 이메일, 전화번호, 주소 같은 사용자 식별 개인정보를 직접 수집하지 않습니다. 찜 목록과 동의 설정은 기기 내 저장소에 보관됩니다.

## Play Console 데이터 유형별 예상 답변

### 개인 정보

- 이름: 수집하지 않음
- 이메일 주소: 수집하지 않음
- 사용자 ID: 수집하지 않음
- 주소: 수집하지 않음
- 전화번호: 수집하지 않음

### 금융 정보

- 앱 내 결제 정보: 수집하지 않음
- 신용카드/계좌 정보: 수집하지 않음
- 할인도사는 결제를 직접 처리하지 않으며 외부 판매처로 이동만 제공합니다.

### 위치

- 대략적 위치: 수집하지 않음
- 정확한 위치: 수집하지 않음

### 앱 활동

현재 앱 코드에는 동의 기반 이벤트 추적 API 구조가 있지만, 운영 서버 저장소와 외부 분석 SDK는 연결되어 있지 않습니다. 운영 환경에서 분석/광고 SDK를 연결하면 앱 활동 수집 여부를 다시 작성해야 합니다.

권장 출시 전 답변:

- 앱 상호작용: 현재 수집하지 않음
- 앱 내 검색 기록: 현재 수집하지 않음
- 설치된 앱: 수집하지 않음

### 기기 또는 기타 ID

현재 광고 SDK, 푸시 SDK, 계정 SDK를 연결하지 않았으므로 수집하지 않음으로 작성합니다. 향후 FCM, 광고, 분석 도입 시 기기 ID 또는 광고 ID 수집 여부를 재검토해야 합니다.

## 데이터 공유

현재 앱은 직접 수집한 개인정보를 제3자와 공유하지 않습니다. 단, 사용자가 외부 판매처 링크를 열면 해당 사이트가 자체 정책에 따라 정보를 처리할 수 있습니다.

## 데이터 삭제

현재 사용자 데이터는 기기 내 저장소 중심입니다.

- 찜 목록 삭제: 앱 내 찜 해제 또는 앱 데이터 삭제
- 찜/최근 본 특가 전체 삭제: 마이 화면의 기기 데이터 관리에서 삭제
- 동의 설정 초기화: 마이 화면의 기기 데이터 관리에서 초기화 또는 앱 데이터 삭제

운영 서버에 계정/문의/푸시 데이터를 저장하게 되면 삭제 요청 창구와 절차를 개인정보처리방침에 추가해야 합니다.

## 출시 전 확인

- [ ] 광고 SDK 없음
- [ ] 분석 SDK 없음
- [ ] 푸시 권한 요청 없음
- [ ] 회원가입 없음
- [ ] 앱 내 결제 없음
- [ ] 개인정보처리방침 URL 입력
- [ ] 외부 링크/제휴 가능성 고지
