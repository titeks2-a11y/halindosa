# 할인도사 Play Console 데이터 보안 작성 가이드

## 현재 앱 기준 결론

할인도사는 비회원도 모든 특가 정보를 볼 수 있는 쇼핑 정보 앱입니다. 사용자가 이메일 또는 소셜 로그인을 선택하면 계정 식별과 동기화를 위해 이메일, 사용자 ID, 닉네임 또는 제공자 프로필 이름 일부를 처리할 수 있습니다. 전화번호, 주소, 결제 정보, 위치 정보는 수집하지 않습니다.

## Play Console 데이터 유형별 예상 답변

### 개인 정보

- 이름: 선택 수집. 소셜 로그인 제공자 또는 닉네임 설정에서 표시 이름 일부를 사용할 수 있음
- 이메일 주소: 선택 수집. 이메일 회원가입 또는 소셜 로그인 계정 식별에 사용
- 사용자 ID: 선택 수집. Supabase Auth user id를 계정 식별과 찜/최근 본 상품 동기화에 사용
- 주소: 수집하지 않음
- 전화번호: 수집하지 않음

### 금융 정보

- 앱 내 결제 정보: 수집하지 않음
- 신용카드/계좌 정보: 수집하지 않음
- 할인도사는 결제를 직접 처리하지 않으며 외부 판매처로 이동만 제공합니다.

### 위치

- 대략적 위치: 수집하지 않음
- 정확한 위치: 수집하지 않음

### 앱 활동

앱에는 동의 기반 이벤트 추적 API 구조가 있습니다. 현재 외부 분석 SDK는 연결하지 않았지만, 운영 서버에서 특가 클릭, 찜 추가/삭제, 최근 본 상품 같은 앱 상호작용을 서비스 품질 개선과 제휴 성과 확인 목적으로 저장할 수 있습니다.

권장 출시 전 답변:

- 앱 상호작용: 수집함. 선택 동의 또는 서비스 제공 목적
- 앱 내 검색 기록: 현재 수집하지 않음
- 설치된 앱: 수집하지 않음

### 기기 또는 기타 ID

현재 광고 SDK, 푸시 SDK, IDFA/광고 ID 기반 추적은 연결하지 않았습니다. 향후 FCM, AdMob, GA4, Firebase Analytics를 도입하면 기기 ID 또는 광고 ID 수집 여부를 다시 작성해야 합니다.

## 데이터 공유

할인도사는 계정 정보와 찜/최근 본 상품 데이터를 앱 기능 제공 목적으로 사용합니다. 사용자가 외부 판매처 링크를 열면 해당 사이트가 자체 정책에 따라 정보를 처리할 수 있습니다. 제휴 링크가 포함될 수 있으며 구매가 발생하면 할인도사가 수수료를 받을 수 있습니다.

## 처리 위탁 및 외부 서비스

- Supabase: 이메일/소셜 로그인, 세션 유지, 회원 프로필, 찜, 최근 본 상품, 관심 카테고리 동기화
- Google/Kakao/Naver 또는 커스텀 OAuth Provider: 사용자가 선택한 소셜 로그인 인증 처리
- 외부 판매처/제휴사: 사용자가 판매처 이동 버튼을 눌러 열린 뒤의 결제, 배송, 환불, 개인정보 처리는 해당 사업자의 정책 적용
- 광고/분석/푸시 SDK: 현재 연결하지 않음. 도입 시 데이터 보안 섹션과 개인정보처리방침을 다시 작성

## 데이터 삭제

- 비회원 기기 데이터 삭제: 마이 화면의 기기 데이터 관리 또는 앱 데이터 삭제
- 찜/최근 본 특가 삭제: 앱 내 찜 해제, 최근 본 상품 비우기, 또는 마이 화면 기기 데이터 삭제
- 회원 계정 삭제: 마이페이지 회원 탈퇴 기능 사용
- 서버 데이터 삭제 기준: `user_profiles`, `user_favorite_deals`, `user_recent_deals`, `price_drop_alerts` 삭제, `deal_click_logs.user_id` 익명화, `auth.users` 삭제

## 보관 기간

- 계정 정보와 동기화 데이터: 회원 탈퇴 또는 삭제 요청 전까지 보관
- 비회원 기기 데이터: 사용자가 앱 내에서 삭제하거나 앱 데이터를 삭제하기 전까지 기기에 보관
- 클릭 로그: 회원 탈퇴 시 사용자 식별자를 제거해 통계 형태로만 보관 가능
- 오류 신고: 운영 품질 확인과 악용 방지를 위해 필요한 기간 동안 보관하되, 개인 식별 정보는 최소화

## 출시 전 확인

- [ ] 광고 SDK 없음
- [ ] 푸시 권한 요청 없음
- [ ] 앱 내 결제 없음
- [ ] 개인정보처리방침 URL 입력
- [ ] Supabase OAuth Provider와 회원 탈퇴 API 실환경 테스트
- [ ] Play Console 데이터 보안 섹션에 이메일, 사용자 ID, 앱 상호작용 수집 여부를 실제 운영 설정과 맞게 입력
- [ ] 외부 링크/제휴 가능성 고지
