# 할인도사 Competitor Analysis

## 뽐뿌

- 장점: 커뮤니티 기반 속도, 검증 댓글, 다양한 핫딜
- 단점: 초보자에게 복잡한 게시판 UX, 앱다운 큐레이션 부족
- 차별화: 할인도사는 카드형 요약, 찜, 카테고리 필터, 알림 중심

## 에펨코리아 핫딜

- 장점: 빠른 반응, 대중적 상품 발견
- 단점: 게시판 맥락 의존, 상품 탐색과 정렬이 제한적
- 차별화: 쇼핑 목적에 맞춘 가격/배송/마감 정보 정리

## 알구몬

- 장점: 핫딜 모아보기와 알림 경험
- 단점: 상세 비교와 운영 큐레이션 확장 여지
- 차별화: 국내 모바일 커머스 UI, Play Store 친화 정책/신고/운영 구조

## 퀘이사존 핫딜

- 장점: 디지털/PC 상품 신뢰도
- 단점: 카테고리 폭이 제한적
- 차별화: 식품, 생활용품, 여행, 무료 혜택까지 포괄

## 핵심 전략

할인도사는 커뮤니티 게시판을 대체하기보다 “놓치기 쉬운 할인 정보를 초보자도 바로 이해하는 앱”으로 포지셔닝한다.
