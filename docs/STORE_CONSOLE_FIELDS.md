## Manual Work That Must Not Be Faked

- Do not claim Play Console or App Store Connect submission has passed until each console shows the uploaded build and review status.
- Do not paste localhost, 127.0.0.1, example.com, private tester credentials, or secrets into public store fields.
- Re-check the privacy and support URLs from an external network before final submission.

## Sensitive Data Rule

Never record keystore passwords, OAuth client secrets, service-role keys, .env values, tester passwords, order numbers, addresses, or payment data in store console fields.
