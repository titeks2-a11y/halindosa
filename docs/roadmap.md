# 할인도사 Roadmap

## 현재 상태

할인도사는 Next.js + Capacitor 기반 Android 앱으로 실행 가능하며, Play Store 내부 테스트에 올릴 수 있는 기본 구조를 갖췄다. 앱 이름, 패키지명, 버전, 아이콘, 스플래시, 정책 페이지, 하단 탭, 찜, 알림, 마이 화면, Android sync, APK/AAB 빌드 검증이 완료되어 있다. V1.0 기준 Deal canonical 모델, mock/staging/production provider 구조, 운영/수익화/푸시/SEO 문서, 홈 discovery 섹션까지 추가되었다.

## 완료 작업

### PHASE 1 UI/UX

- 홈 화면 실시간 할인 정보 피드 구성
- 오늘의 추천, 인기 특가, 마감 임박, 무료배송 특가 섹션 구성
- 상품 카드 이미지 비율 고정
- 할인율, 원가, 할인가, 쇼핑몰명, 배송 정보, 등록/마감 시간 표시
- 찜, 공유, 외부 이동 버튼 배치
- 홈 첫 화면에 `오늘 받을 혜택 큐`를 추가해 무료/쿠폰/무배/마감/구매처 이동을 스크롤 전 바로 고를 수 있도록 개선
- 홈 첫 방문자를 위한 `오늘 먼저 챙길 혜택 판단표`를 추가해 무료 수령, 결제 전 쿠폰, 마감 혜택, 구매처 확인 상품을 사용자가 바로 결정할 수 있도록 개선
- `buildBenefitDecisionGuide`와 `/api/benefits/decision-guide`를 추가해 첫 방문 혜택 판단표를 홈, 알림, 향후 위젯/푸시 후보에서 같은 비회원 기준으로 재사용할 수 있도록 구조화
- 알림 센터에 `알림 혜택 판단표`를 연결해 무료 수령, 결제 전 쿠폰, 마감 혜택, 구매처 확인 상품을 홈과 같은 기준으로 다시 확인하도록 개선

- 운영 대시보드에 `운영 혜택 판단표`를 추가해 고객이 보는 무료 수령, 결제 전 쿠폰, 마감 혜택, 구매처 확인 기준을 운영 보강 큐로 점검하도록 개선
- `/commercialization` 출시 준비 보드에 `출시 전 혜택 판단표 준비도`를 연결해 무료 수령, 결제 전 쿠폰, 마감 혜택, 구매처 확인 상품의 보강 기준을 스토어 제출 전 점검하도록 개선
- 무료 혜택 전용 탭에 `0원 혜택 스타터팩`을 추가해 첫 방문자가 무료/체험/초대권 혜택을 바로 받고 챙김 기록까지 남길 수 있도록 개선
- Deal 모델에 `eligibilityChecklist`, `claimSteps`, `claimWarning`을 추가하고 무료 혜택 카드에 수령 전 체크와 단계형 안내를 노출해 무료/쿠폰 혜택의 조건 확인 UX를 구조화
- `/api/metrics`와 운영 대시보드에 `혜택 조건 보강 우선순위`를 추가해 수령 안내, 링크·신고, 마감 신호가 부족한 혜택 유형을 운영자가 바로 보강할 수 있도록 개선
- `/api/health`에 링크 확인율, 수령 안내 완성도, 무료 혜택 수, 활성 혜택 수를 포함해 VER 2.0 운영 준비 상태를 모니터링할 수 있도록 개선
- `/api/benefits/today`를 추가해 비회원도 열람 가능한 오늘의 무료 혜택, 결제 전 쿠폰, 앱테크·포인트, 마트·편의점, 마감임박, 검증 구매처 큐를 홈/알림/향후 푸시에서 같은 기준으로 사용할 수 있도록 개선
- 오늘 혜택 큐 산출 로직을 `lib/deals/todayBenefitQueue.ts`로 분리하고 알림 센터에 API 기준 큐를 노출해 홈, 알림, 향후 푸시가 같은 무료·쿠폰·앱테크·마감 기준을 재사용하도록 개선
- `/commercialization` 출시 준비 보드에 오늘 혜택 큐 운영 준비도를 추가해 비회원 열람 큐, 무료 혜택, 쿠폰·배달, 구매처 확인 수와 섹션별 대표 노출 후보를 점검하도록 개선

- 주간 혜택 캘린더를 `lib/deals/weeklyBenefitCalendar.ts`로 분리하고 `/api/benefits/calendar`를 추가해 비회원도 볼 수 있는 요일별 무료·쿠폰·앱테크·마트·마감 루틴을 홈/무료혜택/운영 자동화에서 재사용할 수 있도록 개선

## 출시 전 남은 작업

### Critical

- 현재 코드 기준 남은 Critical Issue 없음

### High

- 실제 Play Store 업로드용 signed AAB는 Android Studio 또는 로컬 keystore로 다시 생성해야 함
- 개인정보처리방침 URL을 실제 공개 URL로 배포해야 함

### Medium

- `npm install`에서 moderate 취약점 2개가 보고됨. 강제 수정은 breaking change 가능성이 있어 프레임워크 패치 확인 후 처리
- 실제 운영 데이터는 공식 API, RSS, 제휴 피드, 허용된 수집 방식만 사용해야 함
- 현재 일부 상품은 판매처 검색 fallback으로 이동하므로, 출시 전 제휴/공식 피드로 실제 상품 상세 URL을 보강해야 함

### Low

- 기능 그래픽, 스크린샷, 소개 이미지 제작 필요
- 테스트 사용자 피드백 반영 필요

- 홈의 챙긴 혜택 요약에 `홈 오늘 혜택 미션` 진행 상태를 연결해 무료 혜택 1개 챙기기, 쿠폰 1개 저장하기, 내일 볼 루틴 예약을 앱 첫 화면에서 바로 이어갈 수 있게 개선했다.
- 무료혜택 전용 페이지에 `문화 무료 초대권` 섹션을 추가해 영화 시사회, 전시, 공연, 티켓 이벤트를 별도 레일로 노출하고 바로 받기, 찜, 공유 흐름을 제공하도록 개선했다.
- 문화 무료 초대권 카드에 종료 신고와 링크 오류 신고 진입점을 추가해 시사회·전시·공연 혜택의 마감/오류 정보를 사용자가 바로 운영 큐로 보낼 수 있게 개선했다.
- 무료혜택 화면의 혜택 루틴 카드에 `문화 초대권 찾기` 바로가기를 추가해 영화 시사회, 전시, 공연, 티켓 초대권만 마감순으로 빠르게 좁혀볼 수 있게 개선했다.
- 무료혜택 전용 페이지에 `앱테크·페이·멤버십` 적립 루틴 레일을 추가해 출석체크, 첫 결제 포인트, 페이 리워드, 통신사 멤버십을 매일 확인할 혜택으로 분리하고 바로 받기, 찜, 공유 흐름을 제공하도록 개선했다.
- 홈 혜택 탐색 영역에 `오늘 눌러둘 적립 혜택` 보드를 추가해 출석체크, 페이 리워드, 통신사 멤버십을 앱 첫 화면에서 바로 확인하고 포인트 루틴 필터로 이동할 수 있게 개선했다.
- 카테고리 화면의 생활 혜택 빠른 지도와 목적별 탐색 루틴에 `문화 초대권·무료 관람`, `앱테크 적립 루틴`, `매일 적립할 것`, `무료 관람할 것`을 추가해 문화 혜택과 적립 혜택을 상품 카테고리 없이 바로 고를 수 있게 개선했다.
- `npm run feed:production:doctor`를 추가해 운영 JSON 피드 URL을 설정했을 때 실제 `production` 데이터가 `/api/deals`와 `/api/sources`까지 연결되는지 로컬 fixture로 검증하도록 했다.
- `npm run feed:validate`를 추가해 파트너 피드 파일/URL을 운영 연결 전에 필수 필드, 가격, 상세 URL, 커뮤니티/검색 fallback 기준으로 검수할 수 있게 했다.
- `feed:validate --report` 옵션을 추가해 운영 피드 검수 결과를 ready/needs_fix 행 단위 JSON 리포트로 남기고 수정 우선순위를 확인할 수 있게 했다.
- 운영 피드 검수에 `dealType`, `benefitSummary`, `sourceName`, `expiresAt` 필수 검사를 추가해 공식/제휴 피드가 들어와도 무료·쿠폰·포인트 혜택 조건과 마감 정보가 빠진 항목을 운영 반영 전에 걸러내도록 개선했다.
- 무료혜택 전용 페이지에 `무료 혜택 출석 기록`을 추가해 비회원도 이 기기 기준 연속 확인일, 누적 방문, 다음 행동 루틴을 보며 매일 재방문할 이유를 강화했다.
- 마이페이지와 알림센터에 무료 혜택 방문 기록을 연결하고 기기 데이터 삭제 범위에 `무료 혜택 방문 기록`을 포함해 비회원 재방문 루틴의 표시·안내·삭제 흐름을 맞췄다.
- 홈 화면의 `오늘 챙긴 혜택 요약`에 무료 혜택 방문 연속일과 누적 방문을 연결해 앱 첫 화면에서도 비회원 재방문 루틴을 바로 이어볼 수 있도록 개선했다.
