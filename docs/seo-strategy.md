# 할인도사 SEO / WEB Strategy

## 목표

앱 설치 전에도 검색 유입으로 할인도사를 발견하게 만들고, 앱 설치 또는 재방문으로 연결한다.

## 네이버

- 네이버 서치어드바이저 등록
- 특가 키워드형 블로그 콘텐츠 발행
- `무료배송`, `마감임박`, `오늘 특가`, `항공권 할인` 키워드 랜딩 페이지 운영

## 구글

- sitemap 유지
- 상품 상세 페이지 메타데이터 강화
- `/guide` 서비스 안내 페이지를 색인해 외부 판매처 이동, 가격 변동, 제휴 고지 기준을 검색 사용자에게 명확히 노출
- 가격/배송/마감 시간 구조화 데이터는 실제 운영 데이터 연결 후 검토

## 인스타/유튜브/숏폼

- 15초 특가 브리핑
- “오늘 놓치면 아쉬운 무료 혜택” 시리즈
- 카테고리별 생활비 절약 콘텐츠

## 앱 유입 전략

- 웹 상세 페이지 하단 앱 설치 CTA
- 앱에서 찜/알림/최근 본 특가 기능 강조
- 정책 페이지와 외부 링크 고지로 신뢰 확보
- 서비스 안내 페이지에서 구매 전 최종 가격 확인, 품절 가능성, 직접 판매자가 아님을 반복 안내
