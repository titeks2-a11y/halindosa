# 할인도사 Monetization Plan

## 수익화 원칙

사용자 신뢰를 해치지 않도록 광고와 제휴 가능성은 명확히 고지한다. 가격 정보와 추천 순위는 광고 여부만으로 왜곡하지 않는다.

## 수익 모델

- Google AdMob: 하단 또는 상세 하단 네이티브 광고
- 제휴링크: 판매처 이동 시 성과 측정 파라미터 부착
- 쿠팡파트너스: 쿠팡 상품 링크 전용 disclosure와 sub id 관리
- 오늘의 추천 특가: 검수된 큐레이션 슬롯
- 브랜드 광고: 시즌 캠페인, 기획전 배너
- 프리미엄 노출: 카테고리 상단 스폰서 슬롯

## 예상 수익 구조

- 초기: 제휴 클릭 수익 + 소량 광고
- 성장: 카테고리별 브랜드 캠페인
- 성숙: 가격 데이터 기반 B2B 리포트, 단 개인정보 없이 집계 데이터만 사용

## 광고/제휴 고지 기준

- 상세 페이지와 외부 이동 직전 제휴 가능성 고지
- 광고 슬롯은 `광고` 또는 `스폰서` 표시
- 사용자가 동의하지 않은 분석/제휴 추적 파라미터는 붙이지 않음

## V1.0 미구현

AdMob SDK, 결제, 개인화 광고, 회원 기반 리타겟팅은 구현하지 않는다.
