# 할인도사 콘텐츠 등급 설문 가이드

## 앱 성격

할인도사는 국내 할인 특가 정보를 보여주는 쇼핑 정보 앱입니다. 앱 내에서 직접 결제, 도박, 성인 콘텐츠, 사용자 간 대화 기능을 제공하지 않습니다.

## 예상 답변

### 폭력성

- 폭력적 콘텐츠: 없음
- 폭력 묘사: 없음

### 선정성

- 성적 콘텐츠: 없음
- 노출 또는 성인 상품 판매: 현재 없음

### 언어

- 욕설 또는 저속한 언어: 없음

### 통제 물질

- 주류, 담배, 약물 판매 또는 홍보: 현재 없음
- 향후 특가 데이터에 관련 상품이 들어오지 않도록 운영 필터 필요

### 도박

- 도박, 복권, 베팅: 없음

### 사용자 생성 콘텐츠

- 현재 사용자가 글, 댓글, 이미지, 채팅을 등록하는 기능 없음
- 오류 신고는 운영 검토용이며 공개 게시판이 아님

### 위치 공유

- 위치 정보 수집 또는 공유: 없음

### 앱 내 구매

- 앱 내 결제: 없음
- 외부 판매처 링크 이동: 있음

### 개인정보

- 비회원 열람 가능
- 이메일/소셜 로그인 선택 시 계정 식별 정보 처리
- 찜 목록과 최근 본 상품은 비회원은 기기 저장, 로그인 사용자는 계정 동기화

## 심사 전 운영 필터 권장

- 성인용품, 주류, 담배, 복권, 도박성 이벤트, 의약품성 표현이 포함된 특가 제외
- 외부 링크가 악성 사이트 또는 비정상 리다이렉트로 연결되지 않는지 확인
- 가격/할인율 과장 표현 금지

## 예상 등급

일반 쇼핑 정보 앱 범주로 낮은 연령 등급이 예상됩니다. 단, 실제 운영 데이터에 성인/주류/의약품성 상품이 포함되면 등급과 정책 리스크가 달라질 수 있습니다.
