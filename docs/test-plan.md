# 할인도사 테스트 계획

## 목적

Play Store 내부 테스트와 비공개 테스트에서 앱이 쇼핑 정보 앱으로 안정적으로 동작하는지 확인합니다.

## 테스트 환경

- Android Studio Emulator
- 실제 Android 기기 1대 이상
- 네트워크 정상 상태
- 네트워크 불안정 상태
- 세로 화면 기준

## 핵심 시나리오

### 홈

- [ ] 앱 실행 시 홈 화면이 바로 표시된다.
- [ ] 상단 헤더, 업데이트 시간, 새로고침 버튼이 보인다.
- [ ] 실시간 할인 정보와 특가 카드가 보인다.
- [ ] 오늘의 추천, 인기 특가, 마감 임박, 무료배송 특가 섹션이 보인다.
- [ ] 상품 이미지 비율이 깨지지 않는다.

### 검색/필터

- [ ] 상품명으로 검색된다.
- [ ] 판매처명으로 검색된다.
- [ ] 카테고리 탭 선택 시 목록이 바뀐다.
- [ ] 무료배송만 보기 필터가 작동한다.
- [ ] 핫딜만 보기 필터가 작동한다.
- [ ] 마감임박만 보기 필터가 작동한다.
- [ ] 최신순, 할인율 높은 순, 가격 낮은 순, 마감 임박 순 정렬이 작동한다.
- [ ] 검색 결과 없음 UI가 표시된다.

### 상세

- [ ] 상세 페이지에 이미지, 상품명, 판매처, 가격, 배송, 설명, 추천 이유, 유의사항이 보인다.
- [ ] 구매하러 가기 버튼이 외부 브라우저 또는 Custom Tab으로 열린다.
- [ ] 공유하기 버튼이 작동한다.
- [ ] 찜하기 버튼이 작동한다.
- [ ] 홈으로 돌아가기 버튼이 작동한다.
- [ ] 관련 특가 추천이 보인다.

### 찜

- [ ] 하트 버튼으로 찜 저장이 된다.
- [ ] 앱 재실행 후 찜 상태가 유지된다.
- [ ] 찜 탭에서 목록이 보인다.
- [ ] 찜 해제가 된다.
- [ ] 찜 목록이 없으면 빈 상태 UI가 보인다.

### 알림

- [ ] 알림 탭이 열린다.
- [ ] 마감 임박, 신규, 인기, 무료배송 성격의 알림 카드가 보인다.
- [ ] 실제 푸시 권한 요청이 뜨지 않는다.

### 마이/정책

- [ ] 마이 탭에 앱 소개, 버전, 문의, 정책 링크가 보인다.
- [ ] 개인정보처리방침 페이지가 열린다.
- [ ] 이용약관 페이지가 열린다.

### Android

- [ ] 뒤로가기 버튼이 홈/탭 전환에서 어색하지 않게 동작한다.
- [ ] 하단 탭바가 안전 영역과 겹치지 않는다.
- [ ] 앱 아이콘이 할인도사 이미지로 보인다.
- [ ] 스플래시 화면이 깨지지 않는다.

## 자동 검증

```bash
npm install
npm run lint
npm run build
npm run build:android
npm run cap:sync
npm run smoke:local
npm run qa
npm run qa:release
npm run release:doctor
```

개발 서버가 켜진 상태에서는 아래도 실행합니다.

```bash
npm run smoke
```

`smoke:local`은 개발 서버 실행, 헬스체크 대기, smoke 검증, 서버 종료까지 한 번에 수행합니다.
`qa`는 lint, 로컬 smoke, Next.js build, release doctor를 포함합니다.
`qa:release`는 `qa`에 Android 정적 빌드와 Android/iOS Capacitor sync까지 더한 출시 후보 검증입니다.

## 내부 테스트 기준

- [ ] 최소 3명 이상 설치 테스트
- [ ] 실제 기기 2종 이상 확인
- [ ] 외부 링크 열기 확인
- [ ] 앱 삭제 후 재설치 확인
- [ ] Play Console pre-launch report 확인
