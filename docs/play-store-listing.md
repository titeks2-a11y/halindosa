# 할인도사 Play Store 등록 초안

## 앱 이름

할인도사

## 짧은 설명

실시간 할인 특가와 무료 혜택을 빠르게 확인하는 특가 알림 앱

## 긴 설명

할인도사는 국내 쇼핑몰과 공개 할인 정보를 한눈에 확인할 수 있도록 정리하는 실시간 특가 정보 앱입니다.

핫딜, 무료배송, 마감 임박, 오늘만 진행되는 쿠폰 특가를 모바일 화면에서 빠르게 비교할 수 있습니다. 식품, 생활용품, 디지털, 패션, 육아, 여행, 기타 카테고리별로 원하는 특가를 살펴보고 관심 있는 상품은 찜 목록에 저장할 수 있습니다.

주요 기능:

- 실시간 특가 브리핑
- 카테고리별 특가 목록
- 상품명, 쇼핑몰명 검색
- 무료배송 필터
- 할인율 높은 순, 최신순, 마감 임박순, 낮은 가격순 정렬
- 관심 특가 저장
- 외부 판매처 이동
- 서비스 안내에서 가격 변동, 품절 가능성, 외부 판매처 구매 기준 확인
- 개인정보처리방침과 이용약관 제공

할인도사는 직접 결제나 배송을 처리하지 않으며, 구매는 연결된 판매처에서 진행됩니다. 가격, 쿠폰, 재고, 배송 조건은 판매처에서 최종 확인해야 합니다.

## 추천 카테고리

- 쇼핑
- 라이프스타일

우선 추천: 쇼핑

## 그래픽/스토어 준비물

- 앱 아이콘: 512 x 512 PNG
- 기능 그래픽: 1024 x 500 PNG
- 휴대전화 스크린샷: 최소 2장
- 상세 제작 기준: `docs/store-assets-guide.md`
- 개인정보처리방침 URL: 필요
- 개발자 연락처 이메일: 필요

## 데이터 보안 섹션 가이드

현재 앱 기준:

- 비회원도 모든 특가 정보 열람 가능
- 이메일/소셜 로그인 선택 시 이메일, 사용자 ID, 닉네임 또는 프로필 이름 일부 처리
- 찜 목록과 최근 본 상품은 비회원은 기기 저장, 로그인 사용자는 Supabase 계정 동기화
- 전화번호, 주소, 결제 정보, 위치 정보 수집 없음
- 외부 판매처 링크 이동 있음

향후 광고/분석/푸시 알림 도입 시:

- 앱 활동 또는 기기/기타 ID 수집 여부 재검토
- 데이터 암호화 전송 여부 확인
- 삭제 요청 방법 고지
- 제3자 공유 여부 명시

## 콘텐츠 등급 설문 예상 답변

- 폭력성: 없음
- 선정성: 없음
- 도박: 없음
- 사용자 생성 콘텐츠: 현재 없음
- 위치 정보: 현재 수집하지 않음
- 구매/결제: 앱 내 결제 없음, 외부 판매처 링크만 제공

## 심사 리스크

- 단순 웹뷰 앱으로 보이지 않도록 앱 아이콘, 스플래시, 하단 탭, 찜, 알림, 마이 화면 유지
- 외부 링크와 제휴 가능성 고지 필요
- 실제 운영 데이터 수집 시 권한과 약관 준수 필요
